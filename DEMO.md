### 4. The killer demo — voice-driven video pipeline (works for ANY subject)

Say any of these:

- **"Flat-Out, create a 30 second video for Instagram from yesterday's shoot."** — uses cached Audi RS6 plates (no flux cost, ~$4.20 happy-horse + 0 image gen)
- **"Flat-Out, make a teaser of the Batmobile."** — fresh subject → asks Qwen for 4 cohesive prompts → flux-schnell renders 4 plates → happy-horse animates → stitch
- **"Flat-Out, generate a reel from yesterday's the SUV shoot."**
- **"Flat-Out, create a video of an ice cream van for stories."**
- **"Flat-Out, build a 30s teaser featuring a vintage Land Rover Defender."**

What happens:

1. Voice transcript appears at the bottom of the HUD
2. Speedo flips to **PROCESSING**
3. **Subject extraction** — regex scans first ("of the X", "from yesterday's X shoot") → if no clean match, asks Qwen 32B (~3s)
4. Flat-Out replies with the subject it heard: *"On it. Generating a thirty-three second teaser of the [subject]."*
5. **Cache check** — if `assets/demo-shoot/<slug>/` already has 4 plates, skip flux ($0)
6. **Otherwise**: Qwen generates 4 cohesive flux prompts → 4× `fal-ai/flux/schnell` → save to cache
7. **Animation**: 4× `alibaba/happy-horse/image-to-video` in parallel (2× 5s + 2× 10s, 720p)
8. ffmpeg builds a 3s FOM intro (black + wordmark + dial)
9. ffmpeg fast-cuts the 4 clips into 27 segments (Top Gear / Gran Turismo pacing) — 30s
10. Final 33s vertical 1080×1920 mp4 saved to `output/<slug>_<timestamp>/final.mp4`
11. Speedo flips to **SPEAKING**, fullscreen video overlay opens, mp4 plays automatically

**Total time:** ~120s for cached subjects (RS6), ~150–180s for fresh ones.

**Cost:**
- Cached subject: ~$4.20 (happy-horse only)
- Fresh subject: ~$4.21 (+ $0.012 flux × 4 — negligible)
- After first run, that subject is cached forever; later runs skip image gen.

## Stopping things

```bash

lsof -ti:8766 | xargs kill

# stop static server
lsof -ti:8765 | xargs kill

# stop ollama
pkill -f "ollama serve"
```
