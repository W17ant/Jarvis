STEP 01
Open Terminal

Terminal is the command-line app already on your Mac. Don’t worry — you only need to type a handful of lines.

  1. Hold the ⌘ Cmd key and press the Space bar.
    A search bar appears in the middle of your screen.
  2. Type the word: Terminal
  3. Press Enter.

A black or white window opens with a blinking cursor. This is Terminal. Keep it open — everything else happens here.

What you’ll see A line ending in $. That’s the prompt — it means Terminal is ready for you to type a command.

STEP 02
Download the Project

Two commands. Each one ends with you pressing Enter.

Type this exactly, then press Enter:

$ cd ~/Desktop

This moves into your Desktop folder.

Now type this, then press Enter:

$ git clone https://github.com/W17ANT/Jarvis.git

You’ll see lines flow past — “Cloning into ‘Jarvis’…”, then “Receiving objects… done.”

Takes about thirty seconds depending on your internet.

If it fails You may need Git installed. Type xcode-select --install, click Install on the popup, wait, then try the clone command again.

STEP 03
Run the Installer

This step downloads the AI brain (~25 GB). Coffee time.

Type this, then press Enter:

$ cd Jarvis

Then type this, then press Enter:

$ ./install.sh

The installer pulls in everything Jarvis needs:

  • Ollama — the engine that runs the AI brain
  • Qwen 2.5 — the language model that thinks (~19 GB)
  • Qwen 2.5 Vision — the model that sees your shots (~6 GB)
  • Whisper — the model that hears you
  • Kokoro — the voice that speaks back
  • Supporting tools — ffmpeg, ImageMagick, exiftool

Lines with green ticks ✓ show progress. 10–15 minutes total.

When you see install complete in a box, move to the next step.

STEP 04
Run the Setup Wizard

Configures your voice, brand, folders, hardware tier. Press Enter on its own to keep the suggested answer.

Type this exactly, then press Enter:

$ node tools/setup-wizard.mjs

You’ll be asked, in order:

  • Agent name — default Flat-Out
  • Wake phrase — default hey flat-out
  • Voice — default Daniel (British, Jarvis-tier)
  • Agency name + tagline
  • Brand colours — default FOM red
  • Hardware tier — auto-picked from your Mac
  • API keys — skip any you don’t have
  • Folders — where shoots live, where output goes
Don’t skip this The kiosk needs config/brand.json to start cleanly. The installer prints “Next: node tools/setup-wizard.mjs” at the end — that’s your cue to run it.
Re-run any time Run node tools/setup-wizard.mjs again whenever you want to change a setting. The kiosk picks up the change without restarting.

STEP 05
Launch & Say Hello

One last command, then your studio has an AI.

$ ./launch.sh kiosk

The HUD opens in full-screen Chrome. The speedometer breathes. The corner brackets light up. You’re live.

Try saying:

“Hey Flat-Out, what’s in my diary today?”

If you hear a reply, the install worked.

Everyday use Tap the wake button once, or say “hey Flat-Out”. To exit the kiosk: ⌘ Cmd + Q.
Auto-start on login Run ./tools/install-daemon.sh to register a launch agent so the bridge starts whenever you log in.
If something goes wrong — restart the bridge If the bridge dot in the HUD ever turns red (services stopped responding), open Terminal and run:
$ ./launch.sh restart
That kills every running instance (bridge, Kokoro, Whisper, static server) and starts them fresh. Then refresh the kiosk with ⌘ Cmd + R.

Other useful commands:
  • ./launch.sh stop — stop everything (don’t restart)
  • ./launch.sh kill — same as stop (alternate name)
  • ./launch.sh — windowed test mode (smaller window, easier to debug)

SECTION 01

Voice + Vision

The hands-free layer. Wake it. Ask it. It sees and replies.

Wake on phrase

Say “hey Flat-Out”. Local Whisper transcribes, Qwen thinks, Kokoro speaks. First reply in your ear in about a second.

Sentence-level streaming

You hear sentence one while sentence two is still being composed. Filler phrases (“On it, sir.”) cover thinking time.

Captions every shot

Drop a folder, ask “what’s in the latest shoot?”. Identifies make and model, calls out angle and lighting.

Search by description

“Find the front-grille hero” → ranked file paths. Auto-warms the cache for new folders.

Score for the trailer

Asks Qwen-VL to rate clips on cinematic appeal — subject framing, motion, lighting, peak frame — for picking trailer cuts.

UNINSTALL
Removing Flat-Out

Just as simple as install. The wizard walks through every step and asks before removing anything.

  1. Open Terminal — ⌘ Cmd + Space → type Terminal → Enter.
  2. Navigate to the project folder.
    $ cd ~/Desktop/Jarvis
  3. Run the wizard.
    $ ./tools/uninstall-wizard.sh

The wizard handles, in order:

  • Launch agent — the auto-start on login
  • Running services — bridge, Kokoro, Whisper, kiosk Chrome
  • Tailscale serve config — if you opted in to remote access
  • Project artifacts — node_modules, output, frame cache
  • AI models — the ~25 GB Ollama download
  • Optional: user data — contacts, projects, conversation history (asks first)
Conservative defaults Items that hold your data (contacts, conversation history, AI models that other apps might use) default to No. Only project-only artefacts default to Yes.
Total wipe For a complete wipe including user data and the entire ~/.ollama store, run:
$ ./tools/uninstall-wizard.sh --purge

Flat-Out Jarvis · Diagnosis
FAQ 01

Voice & camera

Mic and camera issues account for ~90% of real-world problems on a kiosk Mac. Run through these before logging a ticket.

I say “hey Flat-Out” and nothing happens

Most common cause: MacBook lid is closed and you’re running off an external monitor — macOS disables the built-in mic in clamshell mode.

Plug in a USB / 3.5 mm mic, or use an iPhone via Continuity (see below). Then open System Settings → Sound → Input and confirm the level meter moves while you speak.

Mic input meter is dead in System Settings

Wrong input device selected, or Chrome doesn’t have mic permission.

In System Settings → Sound → Input, click each device and watch the meter. Whichever moves is your live mic — pick that one. Then in Chrome, visit chrome://settings/content/microphone and confirm localhost:8765 is allowed.

Continuity Camera (using iPhone as webcam) isn’t showing up

iPhone needs to be near the Mac, unlocked, on the same Apple ID, and Continuity Camera must be enabled.

On iPhone: Settings → General → AirPlay & Continuity → Continuity Camera → ON. Both devices must share Wi-Fi + Bluetooth. Re-open the kiosk; the iPhone now appears in System Settings → Sound → Input and as a video source.

Voice replies are very quiet

Output device is the wrong speaker (HDMI display, AirPods that walked away, etc.).

Hold Option and click the volume / sound icon in the menu bar → pick the right output device. The HUD’s volume control is also live in the settings panel.

It hears me but mishears the wake phrase

Background noise is louder than the spoken wake phrase, or the threshold is too tight.

Re-run node tools/setup-wizard.mjs and tweak the wake phrase — shorter, more distinctive phrases get caught more reliably. Or move the mic closer.

FAQ 02

Bridge, services & sending diagnostics

Get back online — or hand Antony exactly what he needs to fix it remotely.

HUD shows a red bridge dot / “connection refused”

cd ~/Desktop/Jarvis && ./launch.sh restart — kills every running instance and starts them fresh. Refresh the kiosk with ⌘ Cmd + R.

Bridge won’t start (Node ABI mismatch from a Homebrew upgrade)

./launch.sh restart auto-detects and rebuilds the native binding silently. If it still fails: npm rebuild better-sqlite3, then restart again.

How do I copy what’s in the browser console?

Right-click in the HUD → Inspect → Console tab → right-click in the console → Save as…. Or ⌘ A → copy → paste.

Bundle everything and email Antony in one command
$ ./tools/diagnose.sh

Writes a tarball to ~/Desktop/flat-out-diag-*.tgz (logs + system snapshot + brand.json, no secrets) and opens a Mail draft to Antony@aoneill.co.uk with it attached. Add a sentence on what broke, hit Send.

Antony shipped a fix — how do I pull it?

./tools/update.sh — backs up memory.db, stashes local edits, git pull, refreshes Node + Python deps, rebuilds bindings, pulls new Ollama models, restarts services. Use --check first for a dry run.

Replies don’t sound like our agency’s voice

No style guide configured. cp config/creative-style.example.md config/creative-style.md, then open -e it and edit. Covers tone, words you use vs avoid, edit pacing — applied to every draft on the next message.

Still stuck? Email Antony@aoneill.co.uk — ideally with the ./tools/diagnose.sh bundle attached. Reply usually within a working day.
